QUICK SETUP
1. Open config.js.
2. Set botName, ownerName, discordInvite, supportEmail, currencyExample, and any wording you want.
3. Replace https://discord.gg/YOUR_INVITE_CODE with the official bot owner's real Discord invite.
4. Upload all files into the same folder on your static hosting provider.
5. Open index.html.

The website is plain HTML, CSS, and JavaScript with inline SVG icons. No build step is required.
Google Fonts are used for typography; system fonts are the fallback.
Before publishing, ensure the legal pages match your actual data practices and add a real support contact.
